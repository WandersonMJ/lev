# Git flow — L.E.V.

Follow the `git-padrao` skill (`.agents/skills/git-padrao/SKILL.md`) for any branch, commit or PR.

Non-negotiable summary:
- Conventional Commits **in English**, body **always required**.
- **Never** add AI co-authorship or AI mentions in commits/PRs.
- Small atomic commits; merge PRs with **Rebase and merge**.
- Never commit `.env`, keys, DB dumps or real personal data.
